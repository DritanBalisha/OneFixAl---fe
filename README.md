🚀 OneFixAL – Frontend

This repository contains the frontend application for the **OneFixAL** platform.


📌 Project Overview

OneFixAL is a platform that connects clients with professional technicians.
Users can book services, manage appointments, and receive real-time notifications.



👉 Project Structure

The project is split into two repositories:

Backend – Go (Gin, GORM, PostgreSQL)
  🔗 https://github.com/DritanBalisha/OneFixAl---be
Frontend (this repo) – React + TypeScript + TailwindCSS



🚀 Tech Stack

Frontend: React + TypeScript
Styling: TailwindCSS
State Management: React Hooks
Backend API: Go
Database: PostgreSQL (Railway)
Deployment:
    Frontend: Vercel
    Backend: Railway



📦 Frontend Structure

```
fe/
 ├── src/
 │    ├── pages/           # App pages (Login, Signup, Home, etc.)
 │    ├── components/      # Reusable UI components
 │    ├── api/             # API requests
 │    ├── styles/          # CSS / Tailwind configs
 │    ├── hooks/           # Custom hooks
 │    └── main.tsx         # Entry point
 ├── public/
 ├── package.json
 └── vite.config.ts
```
